# flutter-pdf-invoice-generator

Client-side PDF generator for e-commerce receipts, invoices, and shipping labels.

`#flutter` `#pdf-generator` `#invoices` `#documents` `#printing`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
// Invoice schema definition
class InvoiceItem {
  final String description;
  final int quantity;
  final double unitPrice;
  InvoiceItem(this.description, this.quantity, this.unitPrice);
}

```
